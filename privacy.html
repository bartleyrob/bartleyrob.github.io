Bike tracker privacy policy

Last updated 24 November 2026.

Who uses it

Bike tracker is a personal, self-hosted app with a single user: the person who runs it. It is not offered to the public.

What it reads

With the user's permission, through Google sign-in, it reads read-only data from that user's own Google Health account: workouts (type, start time, duration, calories, distance, steps), heart-rate samples, and weight and body-fat readings.

How the data is used and stored

The data is used only to show the user their own progress: ride counts, heart-rate graphs and weight charts. It is stored on a private server in the user's home and is not reachable from the internet.

Sharing

The data is never sold, shared, or sent to anyone else, and is not used for advertising or to train any model. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/connections. Deleting the app's data folder removes everything it has stored.
